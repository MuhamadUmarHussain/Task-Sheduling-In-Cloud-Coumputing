# Cloud Task Scheduler

Placeholder project scaffold for a Flask-based research application focused on cloud task scheduling simulation and analysis.

## Folder and File Purpose

- app.py: Flask application entry point.
- config.py: Central configuration placeholders.
- requirements.txt: Python dependency placeholder list.

- data/: Stores input and generated output data.
- data/dataset/: Input datasets for scheduler experiments.
- data/results/: Generated simulation results and exports.

- simulator/: Core simulation and scheduling modules.
- simulator/__init__.py: Marks simulator as a Python package.
- simulator/datacenter.py: Data center and resource modeling placeholders.
- simulator/task_loader.py: Task data loading placeholders.
- simulator/scheduler_fcfs.py: FCFS scheduler placeholders.
- simulator/scheduler_sjf.py: SJF scheduler placeholders.
- simulator/scheduler_eft.py: EFT scheduler placeholders.
- simulator/metrics.py: Evaluation metric placeholders.
- simulator/results_saver.py: Result persistence placeholders.
- simulator/plotter.py: Plotting and visualization placeholders.
- simulator/runner.py: End-to-end simulation runner placeholders.
- simulator/utils.py: Shared utility placeholders.

- routes/: Flask routing layer.
- routes/__init__.py: Marks routes as a Python package.
- routes/main_routes.py: Main web route placeholders.

- templates/: Jinja HTML templates for UI pages.
- templates/base.html: Shared base template placeholder.
- templates/index.html: Landing page placeholder.
- templates/results.html: Results page placeholder.

- static/: Static frontend assets.
- static/css/: Stylesheets.
- static/js/: JavaScript assets.
- static/graphs/: Generated graph image assets.

- reports/: Research documents, summaries, and experiment reports.
